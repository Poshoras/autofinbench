# q025 · Audit an analyst’s figures for look-ahead

- **Revision:** 1
- **Family:** F12 point-in-time audit (reviewer role)
- **Environment:** `step3/env/q025/` — an export from the firm's internal data terminal. **This export is the only permitted information source** (no web search, no memory of actual figures). If something you need is not in the export, say so.

`claims.csv` lists figures that appeared in past research notes (note date, company, XBRL tag, fiscal period end, claimed annual value). `facts.csv` is the filing history for those tags (annual values from 10-K filings, with filing dates; the same period can appear in several filings).

Audit every claim. Classify each as:
- `ok` — the claimed value matches what was publicly filed for that period on or before the note date (latest such filing);
- `pit_violation` — the claim uses information that was not yet public on the note date (a value first filed after the note date, or a period not yet reported at all);
- `incorrect` — any other mismatch.

EPS is in USD/share; other values in USD millions.

```json
{"C01": "ok", "C02": "pit_violation", "...": "incorrect"}
```
