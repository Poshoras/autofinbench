### 第 1 轮 · 反思
1. **题目有效**：8/8 可解，打分和 oracle 一致，没有发现坏题。
2. **太容易，主要原因是题干泄露了陷阱**。例如：
   - q002 直接写了 "like-for-like"；
   - q003 直接要求 "comparable basis" 和拆股系数；
   - q004 给出了 `"blocked"` 选项，还提示"去看看其他文件"；
   - q006 写明 "FY2024 must be as presented in the FY2025 10-K"；
   - q008 写了 "policy prevails — note the conflict"。

   这相当于把陷阱告诉了 agent。各大厂的 agent 评测（例如 OpenAI 的 Blocker Deception）测的是**不提示时**的警觉性。
3. **单跳陷阱不够**：每道题只有一个陷阱。前沿模型在内容全部给定时能一次识别出来。

### 第 2 轮 · 修订方案（依据上面的反思生成概念）
- **新算子"去提示"（unhinted twin）**：同一个环境、同一个 GT，只把题干改写成自然的业务请求，不提陷阱、不给 `blocked` 选项。和第 1 轮的有提示版本配对，能区分"不会做"和"没警觉"。
  - q015 是 q004 的无提示孪生；
  - q016 是 q003 的无提示孪生；
  - q011、q012、q013、q014 都按无提示风格写。
- **新概念 F7**：多期去累计。10-Q 的现金流是 YTD，要算单季度值必须做差分（q009 KO，财季日期是 52/53 周制）。
- **新概念 F8**：复合长链路，在一个时点上算 TTM，需要同时做到三件事：时点筛选、YTD 加减、排除时点之后才提交的 FY2025 10-K（q010 TSLA）。
- **新实例复测**（防选择偏差）：
  - F1 用 PFE（q012）；
  - F3 用 TSLA（q013）：FY2024 的 capex 只被重述了 300 万美元，非常细微；
  - F4 用 70 行的大账本（q014），信息负载翻倍。
